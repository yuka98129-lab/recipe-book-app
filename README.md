# レシピ帳

見つけたレシピを材料・手順つきで保存し、カテゴリーだけでなく「時短」「ダイエット」「栄養重視」などの**用途タグ**でも探せる、レシピを覚えられない人のためのレシピ帳アプリです。

「今日は時間がない」「痩せたい」「栄養を摂りたい」といったその時々の目的に合わせて、保存したレシピをすぐに見つけられることを目指しています。

## 公開URL

https://recipe-book-app-nu.vercel.app

Vercel にデプロイしています。同期の設定をしていない間は、データはお使いのブラウザにだけ保存されます。ログインして同期を使うと、PC とスマホで同じレシピを見られます(下の「同期の設定」を参照)。

## 技術スタック

- [Next.js](https://nextjs.org/) 16(App Router)/ React 19 / TypeScript
- [Tailwind CSS](https://tailwindcss.com/) v4
- データ保存: ブラウザの **localStorage**(いつでも使える基本の保存先)。任意で [Supabase](https://supabase.com/) にもログインして同期できます(設定しなければ、サーバー・外部DBは使いません)
- テスト: [Vitest](https://vitest.dev/)

## 主な機能

- **レシピの登録・編集・削除**: 料理名、カテゴリー、用途タグ、材料・調味料(それぞれ名前と分量)、手順を保存できます。
- **材料グループ**: 「材料」「調味料」に加えて、「トッピング」のように名前を付けたグループをいくつでも追加できます(レシピの「カテゴリー」とは別の機能です)。「材料」は必須、「調味料」と追加グループは任意です。
- **入力のしやすさ**: 材料・調味料などの入力欄で、名前欄の Enter は同じ行の分量欄へ、分量欄の Enter は次の行の名前欄へカーソルを移します(次の行がなければ追加します)。日本語入力の変換確定の Enter では移動しません。空欄の行では行は増えません。
- **調理時間**: 1〜1440 分の整数で、任意で付けられます(全角の数字も使えます)。一覧とレシピ詳細に表示されます。
- **献立カレンダーと買い物リスト**: 画面の下(パソコンでは上)の「献立」から、月のカレンダー(月曜始まり)を開き、日をタップして、その日に作る料理を入れます(1日に何品でも、同じ料理を別の日に入れても大丈夫です)。レシピに人数が入っているときは、**何人分で作るか**を日ごとに変えられ、材料は人数の比で増減します。「買い物の日」から「次の買い物の日」までを選ぶと、その期間の材料を**まとめた買い物リスト**を出します。同じ名前・同じ単位の材料だけを足します(AI は使いません)。「少々」「適量」「2〜3個」などは足さずに書いてあるとおり出します。野菜・肉・魚・調味料などの**売り場ごと**に並べ、材料ごとの**内訳**(どのレシピでいくつ)を見られ、買ったら**チェック**(この端末に覚えます)、**コピー**、**印刷**ができます。献立は端末に保存され、ログイン中は他の端末にも同期されます(`supabase/meal-plan.sql` を1回実行。実行前は、その端末の中だけに保存され、画面に案内が出ます)。献立はバックアップのファイルには入りません。
- **デザイン(あざやか・ポップ)**: トマト色・黄色・ミント色、丸いカード、押せそうな影つきのボタン。スマホでは、画面の下に「レシピ・献立・＋・買い物・設定」のアイコンのボタンが並び、まん中の「＋」でレシピを登録します(パソコンでは上にメニューが出ます)。同期のログインとバックアップは「設定」の画面にあります。写真のないレシピは、色つきの枠になります。栄養素には、たんぱく質・脂質・炭水化物のエネルギー割合(PFCバランス)のバーが出ます。色は `src/app/globals.css` だけで決めています。
- **ホーム画面に追加(アプリのように使う)**: スマホのブラウザで開き、iPhone は共有ボタン→「ホーム画面に追加」、Android は「︙」→「ホーム画面に追加(アプリをインストール)」を選ぶと、アイコンがホーム画面に付き、全画面で開きます(`src/app/manifest.ts`、アイコンは `public/icon-*.png` と `src/app/apple-icon.png`)。
- **話して入れる(音声入力)**: 読み取りの欄の「話して入れる」を押して、「卵3個、玉ねぎ1個、しょうゆ大さじ1で親子丼…」のように話すと、声がブラウザの音声認識で文字になり、文章欄に入ります。「読み取る」を押すと、AIが材料・分量・手順に整理して、入力欄に入れます(話し言葉の聞き間違いや「さんこ」のような言い方も考慮します)。言われていない材料や分量は補いません。音声認識に対応していないブラウザでは、ボタンの代わりに説明が出ます(キーボードのマイクのボタンは、どのブラウザでも使えます)。
- **何人分の材料か**: 1〜100 の整数で、任意で付けられます(「2人分」のように書いても入ります)。一覧と詳細に表示され、AIの読み取りでも、書かれていれば入ります。
- **栄養素の推定(AI)**: レシピ詳細の「栄養素」で「栄養素を推定する」を押すと、材料と分量(と、選べば完成写真)から、エネルギー・たんぱく質・脂質・炭水化物・カルシウム・鉄・ビタミンA/C/D・野菜の量(いも・きのこ・海藻・豆・果物は除く)を、AIが食品成分表をもとにおおまかに計算します。**レシピ全体の合計**を表示し、人数が入っていれば**1人分**も表示します。材料ごとの内訳と、AIが置いた仮定も見られます。結果はレシピに保存され、材料を直すと「古い」と表示されます。あくまで目安で、医療や食事指導の数字ではありません。ログイン中だけ使え、`ANTHROPIC_API_KEY` が必要です。
- **写真(1レシピに1枚)**: ログイン(同期)しているときだけ使えます。スマホではその場で撮影するか、写真から選べます。大きい写真は、長辺1280px・JPEGに自動で縮小してから、Supabase Storage(非公開)に保存します。一覧に小さく、詳細に大きく表示します。写真を使うには、`supabase/photos.sql` を1回実行します(`docs/同期の設定手順.md` の「写真を使うための追加手順」)。バックアップのファイルには写真の画像は含まれません(クラウド側にあります)。
- **写真・文章からレシピを読み取る(AI)**: 登録画面の上の「写真・文章からレシピを読み取る」から、レシピの写真(本・メモ・手書き・スクリーンショット、最大3枚)や、貼りつけた文章(最大8000文字)を AI(Claude)に読ませ、料理名・材料・調味料・手順・調理時間・カテゴリー・タグを入力欄に入れます。**入るのは確認前の下書きです。読み間違い(特に手書き・分量の数字)があるので、必ず確認して直してから登録します。** 自信がなかった箇所は一覧で表示されます。ログイン中だけ使えます。使うには、Vercel の環境変数 `ANTHROPIC_API_KEY` が必要です(下の「レシピ読み取りの設定」)。
- **用途タグ**: 「時短」「ダイエット」「栄養重視」「簡単」「節約」の候補から選ぶか、自由に入力できます。1つのレシピに付けられるのは最大3個です。
- **カテゴリー**: 主菜・副菜・汁物・主食・デザートから選べます。登録時に「新しいカテゴリーを追加」して増やすこともできます。
- **絞り込み**: カテゴリーと用途タグで絞り込めます。タグは複数選択でき、選んだタグをすべて含むレシピだけを表示します。
- **検索**: 料理名・材料・タグ・よみがなで検索できます(全角・半角、ひらがな・カタカナの違いは区別しません)。スペースで区切ると、すべてを満たす料理だけが出ます(例: 「白滝 キャベツ」)。材料で見つかった料理には、「材料: 白滝」のように印が出ます。
- **冷蔵庫の材料から探す**: 一覧の上の「冷蔵庫の材料から探す」を押して、いまある材料を入れると、作れる料理が出ます。「いま作れる(ぜんぶそろっています)」「あと1つで作れる」「あと2つで作れる」に分かれ、足りない材料は「あとキャベツだけあれば作れます」と出ます。調味料は、ふつうは、家にあるものとして数えません(チェックで、数えることもできます)。どれも作れないときは、足りないものが少ない順に、近い料理を出します。入れた材料は URL に残ります。
- **あいうえお順**: 一覧は、料理名のよみがなで、あ行・か行…の見出しごとに並びます。上の「あ か さ た…」ボタンで、その行へ飛べます。よみがなは、登録のとき、空のまま保存するとAIが入れます(ログイン中だけ)。まとめて入れるボタンもあります。ひらがな・カタカナだけの名前は、よみがなが要りません。
- **レシピ詳細**: 材料・調味料・追加したグループ・手順を、見出しごとに分けて表示します。
- **バックアップ**: 一覧画面の「バックアップ」から、全レシピを1つの JSON ファイルに書き出せます(エクスポート)。書き出したファイルを選ぶと復元できます(インポート)。読み込むときは、いまのレシピを残して加える「追加」(同じレシピは重複しません)と、すべて置き換える「上書き」(確認あり)を選べます。形式がおかしいファイルはエラーになり、データは変更されません。
- **同期(任意)**: Supabase にログインすると、レシピがクラウドにも保存され、PC・スマホなど複数の端末で同じレシピを使えます。ネットワークがつながっていないときの変更は端末に残り、つながったときに自動で送られます。いままで端末に保存していたレシピは、初めてログインしたときにクラウドへ送られます。
- **スマホ表示**: スマホの画面幅でも使えるようにレイアウトを調整しています。

絞り込みや検索の条件は URL に保持されるので、詳細画面から戻っても状態が保たれます。

## 起動方法

Node.js と npm が必要です(開発は Node.js 24 で確認しています)。

```bash
npm install
npm run dev
```

http://localhost:3000 をブラウザで開きます(ポートが使用中の場合は、起動時のログに表示される別のポートになります)。

その他のコマンド:

| コマンド | 内容 |
|---|---|
| `npm run build` / `npm start` | 本番ビルド / 本番サーバーの起動 |
| `npm run lint` | ESLint による静的解析 |
| `npm test` | Vitest による単体テスト(`npm run test:watch` でウォッチ) |

## データの保存について

**同期の設定をしていない場合**は、レシピはお使いのブラウザの localStorage にだけ保存され、外部には送信されません。そのため次の点にご注意ください。

- 別のブラウザや別の端末とは共有されません。
- ブラウザのサイトデータを削除すると、保存したレシピも消えます。定期的に「バックアップ」で書き出しておくと安心です。
- URL のオリジン(ホスト名・ポート)が異なると、別のデータとして扱われます(例: `localhost:3000` と `localhost:3001`)。

**同期にログインしている場合**は、上の保存に加えて、レシピの内容(料理名・材料・手順など)が Supabase のデータベースに保存されます。自分のレシピだけを読み書きできるように、行レベルセキュリティ(RLS)を設定します。ログアウトしても、その端末のレシピは消えません。

## 同期の設定

1. Supabase でプロジェクトを作り、[`supabase/schema.sql`](./supabase/schema.sql) を SQL Editor で実行します。
2. Authentication で自分のユーザー(メールアドレスとパスワード)を1人作り、新規登録を無効にします。
3. 次の環境変数を、Vercel(と、手元で動かすなら `.env.local`)に設定して、再デプロイします。

| 名前 | 値 |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | プロジェクトの URL(`https://xxxx.supabase.co`) |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | 公開用のキー(anon key、または publishable key)。**secret / service_role キーは使わないこと** |

`NEXT_PUBLIC_` の値はビルド時にコードへ埋め込まれるため、変更したら**再デプロイ**が必要です。2つとも設定されていないときは、同期の欄が表示されず、これまで通りブラウザ内だけで動きます。詳しい手順は [`docs/同期の設定手順.md`](./docs/同期の設定手順.md) を参照してください。

## レシピ読み取りの設定

読み取りは、サーバー側の `/api/extract-recipe` が Claude API を呼びます。API の鍵はサーバーだけで使い、ブラウザには出ません。

| 名前 | 値 |
|---|---|
| `ANTHROPIC_API_KEY` | (レシピ読み取り・栄養素の推定の両方で使います)Claude API の鍵(**`NEXT_PUBLIC_` を付けない**。チャットやコードには書かない) |
| `ANTHROPIC_MODEL` | 任意。使うモデルを変えたいときだけ(初期値は `claude-haiku-4-5`。手書きの精度が足りなければ、より高性能なモデルに変える) |

- ログインしている本人だけが使えます(サーバーで Supabase のログインを確認)。1人あたり10分に20回までの回数制限があります。
- 1回あたりの費用はモデルと写真の枚数で変わります。使い始めに Anthropic のコンソールで利用料を確認し、月の上限額を設定しておくと安心です。
- 写真は読み取りのために Anthropic に送られます(保存はしません)。他の人の写真・レシピを読み込むときは、その人の了承を得てください。
