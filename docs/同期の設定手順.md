# 同期の設定手順(PC とスマホで同じレシピを使う)

レシピ帳を Supabase につないで、PC でもスマホでも同じレシピを見られるようにする手順です。最初の1回だけ、設定します。

> Supabase と Vercel の画面は、ときどき名前や並びが変わります。書いてある名前が見つからないときは、近い名前のものを探してください。

## 全体の流れ

1. Supabase に、レシピを入れる表(テーブル)を作る
2. 自分用のログインを1つ作り、他の人が登録できないようにする
3. 接続に使う2つの値(URL とキー)を、Supabase で見つけてコピーする
4. その2つの値を、Vercel に登録する
5. 新しいコードを GitHub に反映する(Vercel が自動で公開し直す)
6. PC とスマホでログインして、確認する

**先に 4 を済ませてから 5 をします。** 4 より先に 5 をすると、最初の公開では同期の設定が入っていないため、もう一度、公開し直しが必要になります。

---

## 1. レシピを入れる表を作る

1. Supabase のプロジェクトを開きます。
2. 左のメニューから「SQL Editor」を開き、「New query」を押します。
3. このリポジトリの `supabase/schema.sql` の中身を、すべてコピーして貼り付けます。
4. 「Run」(実行)を押します。
5. 「Success」と出れば完了です。何度実行しても、壊れないように書いてあります。

この表には、**自分のレシピだけを読み書きできる**設定(行レベルセキュリティ)も、一緒に入っています。

## 2. 自分用のログインを作る

1. 左のメニューの「Authentication」→「Users」を開きます。
2. 「Add user」→「Create new user」を押します。
3. メールアドレスとパスワードを入れます。これが、アプリのログインで使うものです。パスワードは、パスワード管理アプリなどに控えてください。
4. 「Auto Confirm User」のチェックが出ていたら、**オン**にします(確認メールを待たずに使えます)。
5. 「Create user」を押します。

### 他の人が登録できないようにする

1. 「Authentication」→「Sign In / Providers」(または「Providers」)を開きます。
2. 「Allow new users to sign up」(新規登録を許可)を**オフ**にして、保存します。

アプリには、新規登録の画面はありません。自分1人だけが使う前提です。

## 3. 接続に使う2つの値を見つける

1. 左下の歯車「Project Settings」を開き、「API Keys」(または「API」)を開きます。
2. 次の2つを控えます。
   - **Project URL**: `https://xxxxxxxx.supabase.co` のような形です
   - **公開用のキー**: 「anon」「public」または「publishable」と書かれているキーです

**使ってはいけないキー**: 「secret」「service_role」と書かれているキーは、**絶対に使わないでください。** これは、レシピ帳の中身を全部読み書きできる鍵で、アプリのコードに入れると、誰でも見られる形になってしまいます。

## 4. Vercel に2つの値を登録する

1. Vercel でプロジェクト(`recipe-book-app`)を開きます。
2. 「Settings」→「Environment Variables」を開きます。
3. 次の2つを追加します。

| Key(名前) | Value(値) |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | 3 で控えた Project URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | 3 で控えた公開用のキー |

4. 環境は、「Production」にチェックが入っていることを確認して、保存します。

## 5. 新しいコードを GitHub に反映する

渡したファイル一式(zip)を開いて、中のファイルを、GitHub のリポジトリに反映します。

1. GitHub で `recipe-book-app` を開き、「Add file」→「Upload files」を選びます。
2. zip を開いて出てきたフォルダとファイルを、そのまま、ドラッグして入れます(`src`、`docs`、`supabase`、`package.json`、`package-lock.json`、`README.md`、`CLAUDE.md`、`requirements.md`)。
3. 下の「Commit changes」を押します。
4. Vercel が自動で公開し直します。「Deployments」で、「Ready」になるのを待ちます。

すでにあるファイルは、同じ名前のもので上書きされます。

## 6. 確認する

### PC で

1. 公開 URL(https://recipe-book-app-nu.vercel.app)を開きます。
2. 画面の下(パソコンでは上)の「設定」を開くと、「ほかの端末と同期する」が出ます。2 で作ったメールアドレスとパスワードで、ログインします。
3. 「同期済みです」と出れば成功です。いままで PC に保存していたレシピが、クラウドに送られます。

### スマホで

1. 同じ URL を開いて、同じメールアドレスとパスワードでログインします。
2. PC のレシピが出てきます。
3. スマホでレシピを登録し、PC で「今すぐ同期」を押すと、PC にも出ます。

**スマホに、前に使っていたレシピがあるとき**: ログインすると、スマホにあったレシピも、クラウドに送られます(消えることはありません)。

## 写真を使うための追加手順

レシピに写真をつけるには、最初の1回だけ、Supabase に「写真を入れる場所」を作ります(同期の設定が終わっていることが前提です)。

1. Supabase の「SQL Editor」→「New query」を開きます。
2. このリポジトリの `supabase/photos.sql` の中身を、すべてコピーして貼り付けます。
3. 「Run」(実行)を押します。「Success」と出れば完了です。何度実行しても、壊れません。
4. レシピ帳にログインして、レシピの登録・編集の画面に、「写真」の欄が出ることを確認します。

**写真について**

- 写真は、ログインしているときだけ使えます。
- 大きい写真は、自動で小さく(長いほうの辺が1280px以下、JPEG)して保存します。1枚あたり、数百KB以下です。無料の保存容量(1GB)で、数千枚ぶんになります。
- 写真は非公開です。ログインした本人だけが見られます。
- 「データを書き出す」のバックアップファイルには、写真の画像は入りません(写真はクラウドにあります)。

## 写真・文章からレシピを読み取るための追加手順

登録画面の「写真・文章からレシピを読み取る」を使うための設定です。AI(Claude)の「鍵」を、Vercel に1つ入れます。

1. Anthropic のコンソール(console.anthropic.com)で、API の鍵を用意します(納品書アプリで使っている鍵と同じものでも大丈夫です)。**鍵は、チャットやコードには書かないでください。**
2. Vercel のこのプロジェクトの「Settings」→「Environment Variables」を開きます。
3. 名前に `ANTHROPIC_API_KEY`、値に鍵を貼り付けて、「Save」します。(名前の頭に `NEXT_PUBLIC_` は付けません)
4. 「Deployments」から**再公開(Redeploy)** します。
5. レシピ帳にログインして、登録画面に「写真・文章からレシピを読み取る」が出て、動くことを確認します。

**気をつけること**

- 読み取りの結果は、確認前の下書きです。特に手書きは、分量の数字を読み間違えることがあります。**必ず確認して直してから**登録してください。
- 1回ごとに、少額の利用料がかかります。Anthropic のコンソールで、月の上限額を決めておくと安心です。
- 他の人のレシピ(お母さんなど)の写真を読み込むときは、本人の了承を得てください。

## 献立カレンダーを、PCとスマホで同期するための追加手順

「献立」(カレンダー・買い物リスト)は、この手順をしなくても、使っている端末の中には保存されます。PCで入れた献立をスマホで見たいときだけ、次の手順をします(1回だけ)。

1. Supabase の「SQL Editor」→「New query」を開きます。
2. このリポジトリの `supabase/meal-plan.sql` の中身を、すべてコピーして貼り付けます。
3. 「Run」(実行)を押します。「Success」と出れば完了です。何度実行しても、壊れません。
4. レシピ帳を開き直して、「献立」の画面にあった黄色い案内が消えることを確認します。

**買い物リストについて**

- 買い物に行く日から、次の買い物の日までを選ぶと、その期間の材料をまとめて出します。
- 「買った」のチェックは、その端末の中だけに覚えます(PCでチェックしても、スマホには出ません)。
- 献立は、「データを書き出す」のバックアップファイルには入りません(同期の表にあります)。

---

## うまくいかないとき

| 症状 | 確認すること |
|---|---|
| 「ほかの端末と同期する」が出ない | Vercel の環境変数が2つとも入っているか確認し、**再公開(Redeploy)** します。値を変えたあとは、必ず再公開が必要です |
| 「メールアドレスまたはパスワードが違います」 | 2 で作ったものと同じか確認します。Supabase の Users で、ユーザーが「Confirmed」(確認済み)になっているかも見ます |
| 「同期できませんでした」 | 1 の SQL を実行したか確認します。ネットワークがつながっているかも見ます。端末のレシピは消えないので、あわてなくて大丈夫です |
| 写真が送れない・出ない | `supabase/photos.sql` を実行したか確認します。ログインしているか(「設定」の「ほかの端末と同期する」)も確認します |
| 「読み取りの設定がまだ終わっていません」と出る | Vercel の環境変数 `ANTHROPIC_API_KEY` を入れたか確認し、**再公開(Redeploy)** します |
| 献立の画面に「献立を他の端末と同期するには…」と出る | `supabase/meal-plan.sql` を実行したか確認します(上の「献立カレンダーを…同期するための追加手順」) |
| スマホにレシピが出ない | 「今すぐ同期」を押します。それでも出ないときは、PC の画面が「同期済み」になっているか確認します |

## 気をつけること

- パスワードは、アプリのログイン欄以外には、入力しないでください。
- 「ログアウト」しても、その端末のレシピは消えません。
- 念のため、時々「バックアップ」で書き出しておくと安心です。
- 不安なときは、ブラウザのデータを消す前に、バックアップを書き出してください。
